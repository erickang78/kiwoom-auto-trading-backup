# 한 주소에서 사용자별로 라우팅하는 로그인 관문

`shared_gateway.py`는 HTTPS 주소 한 개의 로그인 페이지와 세션을 제공한다. `shared_auth.py`의 SQLite 계정 DB는 사용자 이름을 고정된 tenant ID에 연결한다. 모든 화면과 `/v1/*` 요청은 브라우저가 제출한 계좌번호·tenant ID 대신 **세션에서 확인한 tenant ID**로 서버 설정의 정적 화면과 내부 API 포트에 전달한다. 관리자가 독립 tenant와 내부 예약 계정을 미리 만든 뒤 일회용 초대 코드만 전달하면, 사용자는 로그인 화면의 `/signup`에서 사용할 ID와 비밀번호를 직접 정한다. 기존 내부 예약 이름은 가입 시 새 ID로 원자적으로 변경된다. 초대 코드 없이 임의로 계정을 만드는 공개 가입은 허용하지 않는다.

공통 관문은 각 사용자의 백엔드 API 키를 대신 붙이는 신뢰된 구성 요소다. 해당 키는 관문이 읽는 비공개 파일에 두고 HTML·브라우저·로그에 내보내지 않는다. 일반 사용자는 이 설정 파일·계정 DB·다른 사용자의 API 키를 읽을 수 없어야 한다. 사용자별 거래 DB와 실제 주문 프로세스는 기존의 분리된 서비스가 계속 소유한다. 관문이 계좌나 거래 DB를 직접 열지 않는다.

## 기존 운영자 연결

현재 운영자의 이름은 `owner`로 등록한다. `/opt/kiwoom/secrets/tenant-auth.sqlite3`의 salt·비밀번호 해시만 공통 로그인 DB로 이행한다. 비밀번호 원문이나 기존 대시보드 접속 키를 출력·복사하지 않는다. 운영자의 정적 화면은 현재 대시보드 경로를 사용하고, API는 현재 8787 포트로 전달한다. `/v1/backup/status`와 백업 상태 스크립트는 기존 경로를 유지한다. 파일럿 `pilot-001` 사용자는 계정만 비활성 상태로 만들며 초대 코드·키움 인증정보·주문 서비스는 아직 연결하지 않는다.

## 배포 경계

1. 운영 파일과 Caddy 설정을 서버 내부에 백업한다. 관문은 먼저 루프백의 별도 포트(8898)에서만 실행한다. 기존 서비스 8787/8788은 그대로 둔다.
2. 공통 로그인에서 운영자 기존 비밀번호로 로그인 303, 인증 후 대시보드·백업 상태·안전한 조회 API 200, 미인증 API 401을 확인한다. 두 가짜 계정·백엔드로 교차 라우팅 차단도 시험한다. 실제 주문 요청은 보내지 않는다.
3. 검증 후 공개 Caddy 호스트의 내부 대상만 8788에서 8898로 변경한다. 현재 owner 게이트웨이 8788은 롤백용으로 유지한다. 외부 HTTPS 로그인·대시보드·조회 API를 다시 확인한다.
4. 실패 시 Caddy 내부 대상을 즉시 8788로 복구한다. 계정 DB와 시험 자료는 외부 주소에 노출하지 않는다.

두 번째 사용자의 API·매매 서비스는 아직 실행하지 않는다. 나중에 계좌 연결, 사용자별 백업, 장중 동시 부하 시험이 끝나야 실제 매매를 허용한다.
# 회원정보 수정

공통 로그인 관문의 `/account`에서 현재 프로필 사진의 작은 미리보기와 비밀번호 변경(현재·새·확인, 새 비밀번호 10자 이상), 키움 실전 인증정보·업비트 조회 인증정보·카카오톡 알림을 관리한다. 로그인 ID와 내부 API key 변경 양식은 표시하지 않는다. 대시보드 상단 프로필 이미지를 누르면 이동한다. 기존 `dashboard-token`은 백엔드 API 인증 토큰이며 로그인 비밀번호와 별개다. 현재 값은 회원정보 화면에 노출하지 않고 웹 변경 경로도 제공하지 않는다.

운영 설정에는 owner tenant의 `real_credentials_file`, `upbit_credentials_file`, `auto_trading_state_file`을 명시한다. 공통 관문 서비스에는 `/opt/kiwoom/secrets` 쓰기 권한이 필요하다. 키움 실전 인증정보 변경은 자동매매가 정지되고 미처리 주문이 없을 때만 허용하며, 변경 후 계좌 조회로 연결을 확인한다. pilot tenant는 이 경로를 설정하고 해당 tenant 서비스 권한을 준비하기 전까지 변경 버튼을 활성화하지 않는다. 사진은 공유 로그인 관문의 `secrets/photos/<tenant_id>.image`에 제한된 형식·크기로 저장된다.
